# ocw-space — 막사 P0 프로토타입

Open Code War 막사(Space, `DESIGN.md §27`)의 **로컬 전용 프로토타입**입니다.
서버와 통신하지 않습니다. 패널 안에 픽셀 병정이 서 있고, 좌우로 걷고, 채팅하고,
가짜 방문자 3명이 돌아다니며 가끔 말을 겁니다.

**주인 작업 상태는 자동**입니다. 이 컴퓨터에서 돌고 있는 Claude Code 세션(이 mod 가 로드된 세션) 중
하나라도 턴을 진행 중이면 내 병정이 타이핑 모션(⌨)이 됩니다. 세션끼리는 `$.store` 로 상태값만 공유하고,
하트비트가 20초 끊긴 세션은 작업 중으로 치지 않습니다.

> 요구사항: Claude Code **v2.1.287 이상**, 터미널 `claude` 또는 Claude Desktop 의 Code 탭.
> VS Code 채팅 패널·`claude -p` 에서는 그림이 나오지 않습니다.

## 실행

저장소 루트에서:

```bash
claude --plugin-dir ./mods/space
```

프롬프트에서:

| 명령 | 하는 일 |
|---|---|
| `/space` | 막사 패널 열기 (Claude 가 일하는 중에도 열림) |
| `/space-probe` | 사이드카 스트리밍 검사 — node 프로세스가 1초마다 한 줄씩 5번 출력, 실시간으로 도착하는지 측정 |

패널 조작 (패널에 키보드 포커스가 있을 때):

| 키 | 동작 |
|---|---|
| `a` / `d` | 왼쪽 / 오른쪽 이동 (mod 는 방향키를 못 묶습니다) |
| `t` | 맨 아래 채팅 입력창으로. 보낸 뒤에도 입력창에 남아 계속 칠 수 있음 |
| 빈 줄 Enter / `Tab` | 채팅에서 이동 모드로 돌아가기 |
| `Esc` | 막사 닫기 |
| `Ctrl+X` → `Tab` | 패널로 포커스 다시 가져오기 |

코드를 저장하면 `--plugin-dir` 세션이 모듈을 핫 리로드합니다.

## 확인할 것 (DESIGN.md §27.12)

1. 이동 키 반응 — 꾹 누르면 반복 입력으로 걸어가는지
2. 병정 모양 — 터미널 폰트·테마에서 16칸 × 8줄 병정이 어떻게 보이는지
3. **`/space-probe` 결과** — 토스트가 "실시간 스트리밍 OK" 면 P1 에서 WebSocket 사이드카 가능, "몰려서 옴" 이면 폴링
4. 걷기 애니메이션이 끊기지 않는지 (틱 150ms)
7. 다른 터미널에서 `claude --plugin-dir ./mods/space` 로 세션을 하나 더 띄워 일을 시키면, 첫 세션의 막사에서 내 병정이 ⌨ 로 바뀌는지
5. 채팅을 연달아 보낼 때 포커스가 입력창에 남는지, 빈 Enter 로 이동 모드로 잘 돌아오는지
6. Desktop Code 탭에서 Svg 로 그려지는지

## 무엇을 읽고 보내나

- 읽기: `~/.open-code-war/config.json` 의 **닉네임만** (이름표 표시용). `userId` 는 읽어도 쓰지 않습니다.
- 실행: `/space-probe` 때만 `node probe/tick.mjs`.
- 네트워크: 없음.
- Claude 의 턴 시작·끝 이벤트만 봅니다(작업 중 표시). 프롬프트·도구 내용은 보지 않습니다.

`claude plugin validate ./mods/space` 로 훅·호출 목록을 직접 확인할 수 있습니다.
