what is this

Open Code War is the contribution graph for the agent era. A small plugin counts every prompt you submit to Claude Code, Codex, OpenCode or pi — the number of submits and their character count, never the text — and turns it into a rank, a streak, a developer card and a leaderboard.

Privacy-first and open source: no prompt content, no code, no file paths, no stored IP. Verify it in the repository, delete everything with /ocw delete.
