Contact

Email and GitHub are the only official channels

How to reach Open Code War. We are a small open-source project, so there is no phone line and no office open to the public. Pick the channel below that matches your question — technical things go fastest on GitHub, personal-data things go to the privacy mailbox.

01 General, partnership, press

contact@opencodewar.dev — questions about the project, collaboration, media requests, or anything that does not fit below. We aim to reply within 5 business days.

02 Bugs & feature requests

Open an issue at github.com/dodohankim/opencodewar/issues ↗. Please include the agent you use (Claude Code, Codex, OpenCode, pi), the plugin version and what you expected. Pull requests are welcome.

03 Privacy requests

privacy@opencodewar.dev — access, correction, deletion or complaints about personal data. The privacy policy explains the identity check we perform (linked Google email, or the secret id in ~/.open-code-war/config.json for anonymous users). Statutory requests are handled within 10 days. You can also delete everything yourself, instantly: /ocw delete in your agent.

04 Security reports

Email privacy@opencodewar.dev with security in the subject. Please do not file exploitable bugs as public issues; we will acknowledge within 5 business days and credit you if you wish.

05 Maintainer & location

  • Maintainer — dodohankim on GitHub
  • Operated from — Seoul, South Korea (KST, UTC+9)
  • Languages — English, 한국어
  • Also — about · agent guide · API reference

문의

공식 창구는 이메일과 GitHub 두 가지입니다

Open Code War 에 연락하는 방법. 작은 오픈소스 프로젝트라 전화 창구나 방문 가능한 사무실은 없습니다. 아래에서 질문 성격에 맞는 창구를 고르세요 — 기술적인 건 GitHub 가 가장 빠르고, 개인정보 관련은 전용 메일함으로.

01 일반 · 제휴 · 언론

contact@opencodewar.dev — 프로젝트 문의, 협업 제안, 취재 요청, 그 밖에 아래에 해당하지 않는 모든 것. 영업일 기준 5일 안에 답하는 것을 목표로 합니다.

02 버그 · 기능 요청

github.com/dodohankim/opencodewar/issues ↗ 에 이슈를 열어 주세요. 사용하는 에이전트(Claude Code, Codex, OpenCode, pi), 플러그인 버전, 기대한 동작을 적어 주시면 빠릅니다. PR 도 환영합니다.

03 개인정보 요청

privacy@opencodewar.dev — 열람·정정·삭제·불만 제기. 본인 확인 절차(연동한 Google 이메일, 익명 이용자는 ~/.open-code-war/config.json 의 비밀 ID)는 개인정보처리방침에 있습니다. 법정 요청은 10일 안에 처리합니다. 직접 즉시 삭제할 수도 있습니다: 에이전트에서 /ocw delete.

04 보안 취약점 제보

privacy@opencodewar.dev 로 제목에 security 를 넣어 보내 주세요. 악용 가능한 버그는 공개 이슈로 올리지 말아 주세요. 영업일 5일 안에 접수 확인을 드리고, 원하시면 크레딧에 올립니다.
